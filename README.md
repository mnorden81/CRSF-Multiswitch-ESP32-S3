# CRSF-Multiswitch-ESP32-S3

CRSF-Multiswitch mit 8 Kanaelen (ULN2803A) auf einem Waveshare ESP32-S3-Zero, UART A, B und C.

## Aufbau
- `hardware/`: KiCad-Projekt (Schaltplan, PCB, PDF, eigene Footprints). Details, Pinbelegung und offene Punkte in [hardware/README-hardware.md](hardware/README-hardware.md).
- `firmware/`: Firmware, noch nicht begonnen.

## Stand
- Hardware v0.4: PCB vom C3 uebernommen, die Leiterbahnen an U1 fehlen noch (20 offene Verbindungen).
- Firmware: offen.
